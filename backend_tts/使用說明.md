# 🎙️ Azure AI Speech 高品質音檔批次轉檔說明

## 為什麼使用這個腳本？
免費 `edge-tts` 無法指定詞性重音，導致 `presents`（禮物）被念成動詞重音。本腳本透過你的 **Azure AI Speech API Key** 搭配 **SSML `<phoneme alphabet="ipa">`**，能 100% 鎖定正確音標，並一次補齊本次文編修正與遺漏的 8 支音檔：
1. `audio/in_the_usa__presents_are_under_the_christmas_tree.mp3`（修正句型＋鎖定名詞重音）
2. `audio/present.mp3`（鎖定名詞重音）
3. `audio/where_are_the_presents__they_re_under_the_tree.mp3`（鎖定名詞重音）
4. `audio/where_are_the_ornaments__they_re_in_the_tree.mp3`（補齊 v10 遺漏音檔）
5. `audio/chunk_pres.mp3`、`audio/chunk_ent.mp3`（修正 `pres-ent` 音節）
6. `audio/chunk_san.mp3`、`audio/chunk_ta.mp3`（修正 `San-ta-Claus` 音節）

## 執行步驟（Windows PowerShell）
1. 解壓縮後，在專案根目錄打開 PowerShell。
2. 貼上你的 Azure API 密鑰與資源區域（可在 Azure 入口網站「金鑰與端點」查看，常見為 `eastus` 或 `japaneast`）：
   ```powershell
   $env:AZURE_SPEECH_KEY="貼上你的API密鑰"
   $env:AZURE_SPEECH_REGION="eastus"
   python backend_tts/generate_azure_audio.py
   ```
3. 跑完後所有 `.mp3` 會自動存進 `audio/`，**請勿將含有真實 API 金鑰的檔案上傳至公開 GitHub**。

# 🎄 聖誕節大冒險 · Google 試算表統計後台部署指南

## 一、 建立 Google 試算表與 Apps Script (約 3 分鐘)
1. 登入 Google 雲端硬碟，新增一份空白的 **Google 試算表**（可命名為 `聖誕節大冒險_使用統計後台`）。
2. 點選上方選單 **「擴充功能」→「Apps Script」**。
3. 將本壓縮檔內 `backend_gas/Code.gs` 的程式碼**全選複製並覆蓋**貼上，按 `Ctrl + S` 儲存。
   - （選用）若想更改 `admin/stats-viewer.html` 的登入密碼，可修改 `Code.gs` 第 16 行的 `VIEWER_KEY = "xmas2026"`。
4. 點選右上角 **「部署」→「新增部署」**：
   - 類型選擇：**「網頁應用程式」**
   - 執行身分：**「我」**
   - 誰可以存取：**「所有人」**（重要！這樣各校教室開啟教材才能送出計數）
5. 點選「部署」並完成 Google 授權提示後，複製產生的 **網頁應用程式網址**（結尾為 `/exec`）。

## 二、 連結前端教材
1. 用文字編輯器開啟 `js/config.js`。
2. 找到 `window.LESSON_CONFIG.analytics` 區塊，將剛剛複製的網址貼進 `endpoint: "..."` 雙引號內並儲存。
3. 將更新後的專案上傳至 GitHub Pages（或直接發佈），系統即開始自動收集：
   - **第一層（大方向）**：總開啟次數、IP 估算縣市、網址參數 `?area=` / `?school=`、裝置類型、上線時段
   - **第二層（關卡漏斗）**：Story / Words / Culture / Party 進入次數、停留秒數、7 物件全解鎖數、Help 點擊數
   - **第三層（教學細節）**：7 個單字清空重試熱區、介系詞誤選選項、語音慢速（0.75x）比例、文化與 PK 互動

## 三、 觀看統計數據（完全與主程式隔離）
* **方法 A（直接看試算表）**：開啟你的 Google 試算表，第一次收到事件後會自動產生 `raw_events` 與 `01_總覽儀表板`、`02_關卡漏斗`、`03_教學細節` 四個分頁。
* **方法 B（使用獨立檢視網頁）**：在電腦直接雙擊開啟 `admin/stats-viewer.html`（切勿從主畫面連結），貼上同一個 GAS 網址與 `VIEWER_KEY` 即可查看視覺化長條圖與排行。

## 四、 推廣連結範例（精準追蹤各區/各校）
發給彰化或台中合作老師時，可在原本網址後方加上參數：
* `https://你的網址/?area=changhua&school=yuanlin`
* `https://你的網址/?area=taichung&school=demo`
系統會同時記錄該參數與 IP 估算縣市。

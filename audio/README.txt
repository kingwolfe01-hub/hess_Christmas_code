🎄 麥塊聖誕冒險教室 - 音檔資料夾 (audio/)
===========================================
當此資料夾內存在對應的 MP3 檔案時，遊戲會優先直接播放實體高音質音檔，
不再依賴瀏覽器合成語音。

已支援的音檔名稱：
- ornament.mp3 （裝飾彩球）
- present.mp3  （聖誕禮物，名詞 /ˈprɛz.ənt/）

如何生成/更新音檔：
1. 您可以在專案根目錄執行：
   python generate_audio.py
   腳本會自動連線 Google API 生成高音質美式發音 MP3，並自動存入此資料夾。
2. 或者，您也可以將自己錄製或下載的任何標準音檔命名為 ornament.mp3 及 present.mp3 放入此資料夾中。
